# Глоссарий

Термины системы и соответствующие решения (`D-xx`/`F-xx` из [decisions.md](./decisions.md)).

| Термин | Определение | Решение |
|--------|------------|---------|
| **Зрелость тренда** | Шкала `зарождающийся → растущий → устоявшийся → угасающий` | D-06 |
| **On-chain подтверждение** | Рост TVL/объёмов ≥ +10% за 7 дней — тренд «подтверждён деньгами» | D-07 |
| **Pump-фильтр** | Цена ≥ +30% за 7 дней при TVL/объёмах < +10% → «нарратив без подтверждения» | D-08 |
| **Whale («кит»)** | Крупный трансфер ≥ $1M | D-05 |
| **Подтверждение / расхождение / нейтрально** | Вердикт whale-маппинга: whale-активность согласуется с тезисом / противоречит / нейтральна | FR-6 |
| **Анти-повтор (novelty-gate)** | Косинусная близость кандидата к памяти `reported_trends`; ≥ 0.85 → повтор | D-17 |
| **Катализатор** | Событие с датой: unlock/governance/upgrade/regulatory/macro | D-21 |
| **Freshness-декей** | Дельта цены/TVL тренда от первого сигнала (`trend_velocity`) | D-22 |
| **Каталог источников** | Стабильная нумерация `source_id → N` из `sources.yaml`; цитирование `[Ист](N)` | D-16 |
| **Evidence-first** | Каждый тренд подкреплён живой ссылкой и цитатой | инвариант |
| **Fail-open / fail-closed** | Fail-open: ошибка провайдера не роняет прогон (пустой результат). Fail-closed: не выдаём недостоверное (анти-повтор, дисклеймер) | NFR-1, NFR-5 |
| **Agentic loop** | LLM вызывает инструменты (`fetch_url`/`search_web`/`check_onchain`) до N раундов | D-19 |
| **Эмбеддинг** | Вектор `numpy float16` (bge-m3); для анти-повтора считается по `name + definition` | D-11 |
| **Золотой сет** | Размеченный набор «сигнал → ожидаемый тренд» для precision/recall | D-23 |
| **Ретроспективный false-positive** | Проверка pump-флагов через 2–4 недели: памп vs тренд | D-26 |
