## Цель и Definition of Done

Перевести дайджест из «работает» в «стабильный локальный режим» (запуск через
`uv run` или `docker compose`): eval-набор и метрики качества, ретроспективная
проверка пампов, фоновый запуск, обязательные дисклеймеры, мониторинг стоимости и
латентности.

**Приёмка:**

- `make check` (lint + test + security) зелёный.
- CLI `eval` выдаёт precision/recall по золотому набору (старт — 3 приоритетные зоны
  D-09: AI×crypto, DeFi, стейблкоины).
- Ретроспективный false-positive: тренды «нарратив без подтверждения» проверены через
  2–4 недели (памп vs тренд).
- `POST /runs` возвращается сразу (не блокирует), статус по `GET /runs/{id}`.
- Дисклеймер «не является индивидуальной инвестиционной рекомендацией» — в отчёте,
  веб-UI и DOCX.
- Стоимость и латентность прогона фиксируются (`funnel_json`), алерт при массовом отказе
  провайдеров.

## Шаги (по порядку)

1. [ ] **Eval-набор.** `data/eval/` — золотой сет «слабый сигнал → тренд» по 3
   приоритетным зонам (D-09). Утилита разметки (CLI) для ручной/LLM-ассистированной
   разметки первых отчётов. Формат: сигнал → ожидаемый тренд/не-тренд.

2. [ ] **Метрики.** CLI `eval`: precision/recall выхода конвейера против золотого сета
   (FR/NFR-4). Отчёт метрик в Markdown/JSON.

3. [ ] **Ретроспективный false-positive.** Для трендов с флагом «нарратив без
   подтверждения» (pump-фильтр D-08) — проверка через 2–4 недели, вернулась ли цена
   (памп) или закрепилась (тренд). Метрика «ложный тренд vs ложный памп».

4. [ ] **Фоновый запуск.** `POST /runs` ставит прогон в фоновую задачу
   (`BackgroundTasks`/очередь), возвращает `run_id` сразу; `GET /runs/{id}` — поллинг
   статуса. CLI `run` без изменений (синхронный).

5. [ ] **Дисклеймеры.** Аудит: футер отчёта, веб-UI, DOCX, блок интерпретации —
   единый текст «не является индивидуальной инвестиционной рекомендацией» (NFR-5).

6. [ ] **Мониторинг.** Стоимость (LLM/поиск) и латентность фаз в `funnel_json`;
   счётчики отказов провайдеров; лог-алерт при массовом отказе (NFR-1, NFR-2, NFR-3).

7. [ ] **Circuit breaker.** На источниках/провайдерах: N подряд ошибок → временное
   отключение источника в прогоне (fail-open, не роняя весь отчёт).

8. [ ] **Калибровка порогов.** Анти-повтор (косинус) и pump-фильтр — подогнать по eval.

9. [ ] **e2e-тесты.** Полный прогон на fixture-данных; тесты фонового запуска и
    мониторинга.
