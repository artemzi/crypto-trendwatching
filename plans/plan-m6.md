> **Связанные документы:** [plan-m5.md](./plan-m5.md), [plan.md](./plan.md), [requirements.md](../docs/requirements.md), [AGENT.md](../AGENT.md)

## Цель и Definition of Done

Добавить в существующий FastAPI-UI **интерактивный дашборд** по результатам прогона,
чтобы исследовать данные, а не только читать Markdown-отчёт.

**Приёмка:**

- `uv sync` + `pytest` зелёный; работает локально (`uv run` / `docker compose`).
- Страница `/dashboard/{run_id}` показывает графики по выбранному прогону.
- Графики: воронка сигналов, распределение зрелости трендов, on-chain-дельты (TVL/цена),
  whale-потоки, календарь катализаторов.
- Данные берутся из SQLite (без внешних сервисов в рантайме).

## Шаги (по порядку)

1. [ ] **Стек.** Зависимость `plotly` в `pyproject.toml`; локальная копия Plotly.js
   (без интернета в рантайме).

2. [ ] **Эндпоинты данных.** Агрегирующие эндпоинты: `/dashboard/{run_id}/funnel`,
   `/dashboard/{run_id}/maturity`, `/dashboard/{run_id}/onchain`,
   `/dashboard/{run_id}/whale`, `/dashboard/{run_id}/catalysts` — JSON из SQLite.

3. [ ] **Графики.** Воронка (по фазам), зрелость (гистограмма), on-chain-дельты
   (TVL/цена), whale-потоки (объём по активу/времени), календарь катализаторов
   (timeline).

4. [ ] **Страница `/dashboard/{run_id}`** + навигация с главной (`/`) и списка прогонов.

5. [ ] **Тесты.** JSON-контракты агрегирующих эндпоинтов; рендер страницы не падает на
   пустом прогоне.

6. [ ] **Интеграция.** Стилистически совместить с существующим минимальным UI; ссылка
   на дашборд из строки прогона.

## Открытые вопросы

1. **Plotly.js источник.** CDN против локальной копии — для стабильного локального
   запуска предпочтительна локальная копия (зафиксировать в D-записи).
2. **Набор графиков.** Старт с пяти выше; расширять по запросу (например, карта
   переходов зрелости между прогонами).
